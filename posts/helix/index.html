helix terminal based text editor

VScodium

Great out of the box IDE if you don’t want to do any configuration. However, very heavy, electron, I won’t use it everywhere as sometimes it’s way easier to use a terminal text editor. So I wanted to switch.

Micro

Micro was my terminal text editor of choice previous to helix. Really good for making simple changes quickly with no configuration. Also has plugins if you want to extends its usage but I didn’t do any of that.

Helix

Helix is very vim style just simpler to configure. I’d used vim for quite a while so it was easy to pick up. Though, I think most of this community would kill me for my keybinds, I don’t care. My helix keybinds are in my dotfiles on github. I’m really liking it so far, color scheming was easy to set up, has the ability to have all the keybinds you want mapped however you want, and doesn’t require learning a whole language to configure.

I’m sure my current keybinds will change before they settle, but I’m very much a 20% effort for 80% of results person when it comes to things like this. Some people spend hours on writig lisp for their emacs and get into a sunk cost fallacy situation. VScodium worked well for me but it is missing some keybinds, for example gw to go to word is very helpful to me. So I get more utility out of this but also I can use it everywhere, unlike with an IDE where you have to open the file in it interrupting your terminal workflow. Also this is far more keyboard based, I’ve been using my thinkpad a lot more lately and it’s nice to increase the keyboard usage in my workflow considering trackpads are suboptimal.
