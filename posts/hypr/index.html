Giving in and using a wm: hyprland

Prior WM/DE experience

My main desktop is KDE, as I don’t care about ram, have two screens, and KDE still allows for a lot of keyboard usage. It also in my experience has been very familiar to anyone who grew up using computers and is reliable while still being reasonably customizable. I’ve also used Cinnamon and XFCE when I needed a lightweight DE. Other than that I had quite a good experience using mangowm while I was on my Artix Linux bender. I’ve been using my laptop way more recently, because of the lack of a mouse and limited screen space I’ve decided it’s time to switch to a WM as I’d previously had Debian with Cinnamon. Though, because I use my laptop for college I wanted something that had been around, will be around, will work every time, has a decent sized community (which ties into reliability), and is easy to set up / configure. So I decided I’d finally see why so many people love Hyprland.

My hyprland experience

Overall I’d say 10/10. I was used to the old hyprland which used a config file instead of lua, and mango also uses a config file, so the lua bit was sort of odd to me. However, I just used AI to set up most of the things because I’m not pouring over documentation for both hyprland and lua for 15 minutes to set up 1 keybind. To install it archinstall does come with hyprland as one of its listed profiles. Installing it manually is very easy yes but I also wanted archisntall to set up services like pipewire, bluetooth, disk encryption etc. The defaults and methods archinstall uses are pretty congruent with how I’d do it manually so I just did that. Standard Arch with default kerne, ext4 no LVM, swap enabled, monolithic partitioning, etc etc. For the Hyprland side of things I’m using swaybg and waybar, because they’re simple to set up and pretty static, I don’t need a movie rendering animation phonk edit background changer thats 300 lines of lua so I can change my background between 300 different AI generated anime girls when I feel like it (like some people).

Last note, one thing that really surprised me was Hyprland had out of box native support for FIDO authentication even with electron apps. KDE doesn’t even do that so bravo.
