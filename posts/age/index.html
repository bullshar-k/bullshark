Manual keygen, encryption, and decryption with age

From the wireguard tunneling, to matrix, to IRC, and now manually encrypting and generating keys with age, I keep visiting cryptography for different reasons and loving it more every time I do.
I think it’s the perfect specialization in between network engineering, my forte, and software engineering, a secondary passion of mine which I’m not quite as good at.

Keygen

Creates post quantum public and private key in a file, also echoing the public key to the terminal:

age -pq -o key.txt

Private key file encryption decryption

If you are going to be storing this key as a “just in case” so someone can send something to you with it if need be I would recommend encrypting the file with the private key using a password.

To encrypt private key file with password:

age -p key.txt > key.txt.age

To decrypt private key file with passwsord:

age -d key.txt.age > key.txt

Message encryption decrpytion

Encrypt using someones pubkey to send to them:

age -r age1..... -o message.txt.age message.txt

  • age1….. is the public key

  • message.txt.age is the desired encrypted output file name

  • message.txt is the file you wish to encrypt

To decrypt a recieved file echoing it into the terminal:

age -d -i key.txt encrypted_message.txt
  • key.txt will be the generated file with pub and private key
  • encrypted_message.txt is the encrypted file sent to you

To decrypt a recieved file into file:

age -d -i key.txt encrypted_message.txt > decrypted_message.txt
  • decrypted_message.txt will have the outpute of decrypting encrypted_message.txt with key.txt
