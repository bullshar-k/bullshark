vyOS

Intro

I really do love vyOS. It gives you a real router feel unlike PFsense or OPNsense, the CLI workflow efficiency, and the linux networking all in one.

Setup

Running in a proxmox VM, vyOS ver 2026.03 generic rolling. I did have to make the VM BIOS for it to boot but the installation was braindead easy. The default user and password is vyos. Then you run install image and [y/n] your way through it, reboot, and now vyOS is on your partition. I did have an obstacle however. See my Adguard broke. I had somehow disabled CPU virtualization which made KVM and QEMU not doable, so I had to turn it off to re enable that. I thought the DNS queries not hitting was because of the router. So I spent a minute wondering the router was stopping a DNS on the same LAN from resolving when the PC and the DNS server could ping the internet. I decided surely it was just Adgaurd despite the odd timing of having a new router, so then I just decided to go with the trusty snapshot rollback and everything worked swellingly.

Comments

Some of the docs are outdated. One example being for this command the word ‘option’ isn’t included. Though if you know how to use the ? on Cisco IOS it becomes a 2 second obstacle.

set service dhcp-server shared-network-name LAN subnet 192.168.1.0/24 option default-router '192.168.1.1'

Other than that it kind of likes to flip out, once I set up SSH and was able to use it through my PC’s terminal instead of the proxmox web VNC it was a little better, but tab completing incomplete commands can sometimes paste the output into your line and it gets all freaky. CTRL + C usually fixes it well enough though. Other than that im overall very happy, OPNsense and PFsense are both built on FreeBSD which is sorta more secure but has its own bout of problems. Its nice to have actual CLI router like networking with linux.

I sort of went to set up DHCP but ended up not because I don’t have a WAP and basically never connect new devices to my network, so thats why DHCP is set to disabled but has some configurations.
